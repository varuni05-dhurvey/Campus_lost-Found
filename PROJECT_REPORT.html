1. Abstract

On modern collegiate campuses, students, faculty, and administrative staff routinely misplace personal belongings—ranging from student identity smart cards and scientific calculators to high-value laptops, wireless earphones, keys, and wallets. Traditional campus recovery relies on chaotic WhatsApp groups, physical bulletin boards, or word-of-mouth inquiries. These approaches suffer from severe communication fragmentation, zero auditability, privacy exposure, and risks of fraudulent claims.

The Campus Lost & Found Portal resolves these inefficiencies through an authenticated, role-based web platform. Engineered using React.js (Frontend), Node.js & Express.js (REST API Backend), and MongoDB (Database), campus members can catalog lost items, list found belongings, and claim property through a privacy-preserving verification mechanism. Identifying secrets (such as serial numbers or custom stickers) remain hidden from the public feed and are only revealed to verified owners and moderators.

2. Objectives & System Architecture

The system is designed with a 3-Tier Modular Client-Server Architecture:

  • Presentation Tier (Frontend): React 18 single-page application bundled with Vite. Styled with a custom collegiate CSS3 design system using Flexbox, CSS Grid, and custom variables in navy and emerald.
  • Application Tier (Backend):** Node.js and Express.js RESTful API structured into modular controllers, routes, JWT authentication middleware, and Multer file upload handlers.
  • Data Tier (Database): MongoDB database with Mongoose schemas and compound indexes on search fields.

Claims POST /api/claims Private Submit claim with secret identifying evidence
